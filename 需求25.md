你指出的矛盾是对的，我同意修改设计。

请把 **between-repetition consistency 明确限制在 Full Calibration**，不要把它作为正常 Quick Check 的必需条件。

新版职责划分：

### Full Calibration

每个 finger state 做约3个 staged repetitions：

Open / C / Pinch × 3

每个 repetition 都使用：

屏幕提示
→ 人工确认姿态已摆好
→ WAIT_FOR_STABILITY
→ RECORD_STABLE_WINDOW

Full Calibration 用这些 repetitions 建立：

* participant-specific state reference
* within-hold variability
* between-repetition variability
* normalized C position distribution
* state separation
* acceptable participant-specific action space

### Quick Check

正常 Quick Check 每个状态只采一次：

* Open × 1
* C × 1
* Pinch × 1
* Wrist Neutral × 1

仍然使用 staged acquisition：

人工确认
→ stability detection
→ short stable recording

Quick Check 不重新估计 repetition variability。

它只检查：

1. current-state validity

   * stable
   * Open > C > Pinch
   * reasonable separation / geometry

2. saved-calibration compatibility

   * 当前 Open 是否仍被 saved model 判为 Open
   * 当前 C 是否仍被判为 C
   * 当前 Pinch 是否仍被判为 Pinch
   * 当前 neutral 是否仍落入 saved neutral-centered region
   * classification ratio / boundary margin

participant-specific tolerance 应来自 Full Calibration 已经测到的 repetition variability。

### Failed-state retry

如果 Quick Check 中只有某一个 component fail，不需要把整个 Quick Check 全部重新做。

例如：

Open PASS
C FAIL
Pinch PASS
Wrist PASS

则只：

提示 participant 重新做标准 C
→ 人工确认
→ stability detection
→ reacquire C once

这属于 **targeted quick-check reacquisition**，不是 targeted recalibration，因为不能更新 saved reference。

如果 failed component retry 后 PASS：

→ reuse old calibration

如果 retry 后仍 FAIL：

→ full recalibration

第一版暂时仍然不做 targeted partial recalibration。

另外，我同意取消把 `Open → C → Pinch → C → Open` 作为必须的 continuous calibration sequence。

第一版 calibration 可以使用更容易调试和解释的 staged states：

Open → C → Pinch

Full Calibration 重复3轮；Quick Check只做1轮。

每个state都是独立提示、独立人工确认、独立稳定检测和独立记录，不能自动从连续动作中 segmentation。
